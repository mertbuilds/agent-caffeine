- Agent Caffeine is now free and open source. There is no trial and no license key. If you bought a key, you get your money back, and you do not have to do anything.
- The source code is on GitHub, under the AGPL license. Settings > About has the link.
- New agents: Grok Build, Hermes Agent and OpenClaw.
- New command line tool `agent-caffeine`: a script or an agent can ask your Mac to stay awake for a time, or while a command runs. It also works as an MCP server.
- "Set up for agents" in Settings > Agents teaches your agents to use the tool, with one click.
- Wake for jobs (off by default): your Mac wakes for a scheduled job and stays awake while the job runs.
- Closed lid limit: with the lid closed on battery, agents stop keeping your Mac awake after 3 hours or when the battery lost 30 points, so a session that hangs does not empty the battery in a bag. Command line holds and scheduled jobs are not stopped. You can change both in Settings > Battery and lid.
- Offline rule: when your Mac is offline for 10 minutes, agents stop keeping it awake, because an agent cannot work without the internet. Command line holds, scheduled jobs and an agent that runs a busy command are not stopped. You can change the time in Settings > General.
- A short sound says that your Mac stays awake when you close the lid.
- Fixed: Claude Code sessions that run on after Claude Code updated itself are seen again.
- Fixed: a background command that a Claude Code session left running no longer keeps your Mac awake all night.
- Fixed: the Claude desktop app no longer reads as working for hours while it is idle.
