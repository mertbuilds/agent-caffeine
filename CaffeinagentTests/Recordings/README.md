Lab recordings that `LabReplayTests` replays on every test run. Each `*.jsonl` here must replay with zero wrongly released seconds and with wrongly held seconds within the `wronglyHeldBudget` of its header. Record with `caffeinagent --lab-record <label>`, mark with `--lab-mark`, then copy the file from `~/Library/Application Support/com.caffeinagent.app/lab/`.

`synthetic-openclaw-gateway.jsonl` is cut from a recording of 2026-10-08 (docs/research/12-openclaw.md, section 7): the OpenClaw gateway alone, with its CPU use, its writes, its child commands and the verdicts the app gave then. `OpenClawRecordingTests` replays it.

`synthetic-claude-background-shell.jsonl` is the trap of 2026-10-10 (docs/research/01-oss-detection.md, section 9), written by `LabReplayTests.backgroundShell`: a turn of Claude Code starts a dev server and ends, the session file says `shell` from then on, the lid is closed and the Mac is on battery. The rule holds for the release time after the last busy sample of the server, which is 175 seconds more than the score allows after a mark, so its budget is 350 seconds for the two times the server goes quiet.

`synthetic-claude-deleted-version.jsonl` is the trap of 2026-10-12 (docs/research/01-oss-detection.md, section 10), written by `LabReplayTests.deletedVersion`: a session and a background session of Claude Code work with the lid closed, on battery, and an update deleted the files of their versions. Each agent of a frame has `gone` for that. Before that date the app did not see such a session at all, so a recording of that time has no agent to replay.
